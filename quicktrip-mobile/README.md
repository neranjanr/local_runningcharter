# QuickTrip Mobile — PWA staging to Buffer Sheet

Installable PWA (Add to Home Screen) that mirrors `components/QuickTripForm.tsx` capture but writes to a **Buffer Sheet** via **Sheet Proxy** (Apps Script), not the deployment DB.

## Folder contract

- Lives in sibling `quicktrip-mobile/` (Adr 0014) — v1 also exposed as `app/mobile/` route sharing `lib/` for single-deploy. This folder is the isolated PWA when you want a separate deploy.
- Shares math from `../lib/tripCalculations.ts` (copy or symlink) — keep `Integer KM`, `Estimated Start Time = End − Distance/speed tiered <10→15 <20→20 <40→25 ≤60→30 >60→35 ceil 5min`, Duration reciprocals identical.

## Setup

1. Create a Google Sheet with headers exactly `lib/allTripsWorkbook.ts:18` (`Date | Start KM | End KM | Distance | Start Time | End Time | Private / Official | Places Visited | Fuel Pumped | Fuel Order No`). Name it e.g. `QuickTrip Buffer`.
2. Extensions → Apps Script → paste `../quicktrip-mobile/apps-script/Code.gs` (or `docs/mobile/apps-script.gs`), Deploy → Web App → Anyone with link (or restrict to your account), copy URL.
3. Add storage: `config/sheet.local.json` (gitignored, see `config/sheet.example.json`) → `{ "scriptUrl": "https://script.google.com/.../exec" }` — shared with main app `lib/sheetConfig.ts`. Alternatively set `$ScriptUrl` at top of `start-service.ps1` (PS1 overrides config).
4. Build private single-file: `npm run build:mobile` (or `start-service.ps1` auto-runs it) reads `$env:SCRIPT_URL` from PS1 or `config/sheet.local.json` and injects URL into `quicktrip-mobile/dist/mobile_app_public.html` → `quicktrip-mobile/dist/Mobile_with_url_private.html` (gitignored). Copy the private file to phone; the public template `mobile_app_public.html` (tracked, no secret) requires pasting URL via Settings.
5. On phone: open private file in Chrome → Add to Home Screen (no Settings paste needed, URL hard-coded) or open public file → Settings → paste Script URL (persisted in localStorage). First load fetches `?action=last10` to seed `Start KM` (remote truth, amber badge).
6. `npm install && npm run dev` (port 3001 to avoid clash with main app 3000).

## Distribution — why two files?

- `quicktrip-mobile/dist/mobile_app_public.html` — **tracked**, `SCRIPT_URL_DEFAULT = ""`, no secret. Safe to push to GitHub. User must paste URL once in Settings (localStorage) or use `?scriptUrl=` param.
- `quicktrip-mobile/dist/Mobile_with_url_private.html` — **gitignored**, generated by `npm run build:mobile` / `start-service.ps1` from PS1 `$ScriptUrl` or `config/sheet.local.json`. Single-file standalone; copy to phone via USB/Drive and it works immediately (hard-coded URL + offline queue). Never pushed.
- How it takes URLs when only copying one file? The file is fully self-contained: `SCRIPT_URL_DEFAULT` is inlined at build time (from PS1/config), plus `localStorage mobile.scriptUrl` fallback and Settings panel for override. No external fetch for config — the URL travels inside the HTML. PS1 is the writer: edit `$ScriptUrl` at top of `start-service.ps1`, run it, and it rewrites the private file.

## Features

- Same reciprocals, validations, fuel rounding as web QuickTripForm.
- Last 10 rows table (read-only) from `GET ?action=last10`.
- Offline queue: IndexedDB (`mobile-queue`) stores trips when `navigator.onLine===false` or fetch fails; background flush on `online` + `visibilitychange`.
- Import closure: Download Buffer Sheet as `.xlsx` → main app `All Trips` → Import (headers order-enforced via `validateHeaders`). Future direct pull: main app `GET scriptUrl?action=allRows`.

## Import test

- Buffer `.xlsx` must pass `parseAllTripsWorkbook` error-free before deployment will accept it — good smoke test before upload.
