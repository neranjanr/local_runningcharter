# Pump Timing and refined fuel economy estimation

Pump Timing boolean (`START` vs `END`, default `END`, DB `trips.pump_timing`) replaces the proposed 0-100% share for mid-trip refuels (grill 2026-09-28). A `START` pumped Trip with `trip_distance>20` migrates its distance into the next Fuel-In Segment (fuel available for this Trip, charged to next economy); `END` keeps it in the previous segment (current behaviour). Percentage rejected as over-precise and requiring intra-Trip split; binary keeps single economy per Trip, trivial workbook validation, and matches the user's mental model ("fueled at start vs end"). Guard `>20km` ensures short hops stay deterministic; UI shows control for all pumped Trips but estimator ignores `START` when `distance≤20`.

Estimator refined (same grill): Full→Full intervals remain physics-first (`totalDist/totalFuel` raw, nearest feasible), otherwise lenient segments use nearest feasible to previous economy (small variations, seed 7.8 km/L first segment) to avoid large jumps. Feasibility is per-Trip balance in `[1, tankCapacity]` (Strict tightens Full source to `[cap-3, cap]` after pump). Safe margins use vehicle `typical_low/high ±20%` else fallback `4-30 km/L ±20%` for amber warning only; hard brute remains `0.1-50` so lorry/bus/hybrid extremes still feasible.

Considered Options: 0-100% `fuel_pre_share` with intra-Trip consumption split — rejected requiring two economies per Trip and breaking `Fuel-In Segment` single-economy invariant. `START`/`END` share kept estimation-only (ledger balances follow assigned economy) without splitting DayGroup economy. Strict Full→Full biased toward previous (0.7*prev+0.3*raw) — rejected; physics should dominate Full→Full.

Consequences: Workbook/Sheet/Proxy gain trailing `Pump Timing` column (12-col, `START`/`END`, empty→`END`, legacy 10/11-col defaults), mobile and QuickTrip forms add radio beside Full Tank, All Trips ⋯ menu toggles timing on pumped rows, `estimateFuelEconomy.ts` and `computeTripFuelMap` respect migration, `CONTEXT.md` adds `Pump Timing` and updates `Fuel-In Segment`/`Estimated Fuel Economy`/`All Trips Workbook`/`Buffer Sheet`.
